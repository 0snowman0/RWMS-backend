Mapper Quick Guide

1. استفاده در Controller
   Mapper را از طریق DI بگیر:

```python
mapper: MapperDependency
```

Controller فقط با `IMapper` کار می‌کند.

---

2. توابع اصلی Mapper

`map(source, destination_type, *, ignore_none=False, ignore_unset=False)`

کاربرد: تبدیل یک Object به Object جدید.

```python
dto = mapper.map(user, UserDto)
user = mapper.map(dto, User)
```

ورودی‌ها:

* `source`: آبجکت مبدا
* `destination_type`: کلاس مقصد
* `ignore_none`: فیلدهای `None` مپ نشوند
* `ignore_unset`: فقط فیلدهای واقعاً مقداردهی‌شده مپ شوند

`map_list(source, destination_type, *, ignore_none=False, ignore_unset=False)`

کاربرد: تبدیل لیست آبجکت‌ها.

```python
dto_list = mapper.map_list(users, UserDto)
```

`map_to(source, destination, *, ignore_none=False, ignore_unset=False)`

کاربرد: مپ روی Object موجود؛ مناسب Update/PATCH.

```python
mapper.map_to(
    request,
    user,
    ignore_unset=True,
)
```

---

3. Mapping معمولی

اگر نام فیلدها یکسان باشد هیچ Configuration لازم نیست.

```text
DTO.email      -> User.email
DTO.full_name  -> User.full_name
```

فقط:

```python
user = mapper.map(dto, User)
```

---

4. Mapping خاص

Configuration فقط برای موارد استثنایی لازم است:

* نام فیلدها متفاوت باشد
* Transform لازم باشد
* چند فیلد به یک فیلد تبدیل شوند
* فیلدی Ignore شود

Configurationها داخل `MappingProfile` نوشته می‌شوند، نه داخل Controller یا Service.

---

5. دستورات Configuration

```python
create_map(SourceType, DestinationType)
```

ثبت Mapping خاص.

نام متفاوت:

```python
.for_member(
    "full_name",
    source="name",
)
```

Transform:

```python
.for_member(
    "price",
    source="price",
    transform=lambda value: value * 2,
)
```

Resolver:

```python
.for_member(
    "full_name",
    resolver=lambda src: f"{src.first_name} {src.last_name}",
)
```

Ignore:

```python
.ignore("id")
```

---

6. نمونه Profile

```python
class UserMappingProfile(MappingProfile):

    def configure(self, mapper: Mapper) -> None:

        mapper.create_map(
            UserCustomDto,
            User,
        ).for_member(
            "full_name",
            source="name",
        ).for_member(
            "is_active",
            source="status",
            transform=lambda value: value.lower() == "active",
        )
```

---

7. ثبت Configurationها

تمام Profileها در:

```text
mapping_configuration.py
```

ثبت می‌شوند.

`configure_mapper()` فقط یک بار اجرا می‌شود و Mapper آماده از طریق DI در اختیار Controllerها قرار می‌گیرد.

---

قاعده کلی:

```text
فیلدهای هم‌نام      -> بدون Configuration
Mapping خاص         -> Profile
Create              -> map()
List                -> map_list()
Update Object موجود -> map_to()
```
